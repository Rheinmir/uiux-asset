jang.work UI kit

Hệ thiết kế của portfolio jang.work, gồm hai lớp. Lớp shell design:os có thang Fibonacci cho khoảng cách và cỡ chữ, line-height theo tỉ lệ vàng, dải xám 100–1200, thẻ khung đôi. Lớp bài viết dữ liệu có bộ token riêng trong từng trang, gồm tiêu đề serif và một accent cho mỗi bài.

Mọi màu và số đo lấy từ CSS thật của site hoặc từ getComputedStyle trên 276 pattern ở 16 trang. Muốn dùng lại: bấm “Copy CSS token” để lấy khối :root, rồi copy HTML từng thẻ. Class .jw-* chỉ tham chiếu biến.

  • 710px--w-container
  • 668px--w-measure
  • 5px--frame-inset
  • 1.618--lh-text
  • 2·5·8·13·21·34·55·89·144--sp-*
  • 44px--tap-min
  • 200ms--dur-base

Chữ

Shell dùng Inter (400/450/500/550/600) và JetBrains Mono, trích dẫn dùng Libre Baskerville. Bài viết: tiêu đề Merriweather, thân Arial 20/1.7. Thang cỡ: 13·16·21·26·34·42·55·68·89·110.
