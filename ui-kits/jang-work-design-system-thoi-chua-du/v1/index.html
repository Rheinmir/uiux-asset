Bài “Design system thôi chưa đủ” · UI kit

Hệ giao diện của một bài viết dữ liệu trên jang.work. Bài tự khai token trong <style>: 12 vai trò màu (paper, thẻ trắng, hairline, ink, relation xanh cho quan hệ, violation cam cho vi phạm), ba font (Merriweather, Arial, Inter), ba mức bo (4 · 8 · 14). Quy ước của bài: viền đứt = ví dụ giả định, xanh = quan hệ, cam = vi phạm, “không dùng màu đỏ”.

Màu và số đo chép từ CSS của bài và từ getComputedStyle trên 72 pattern. Muốn dùng lại: bấm “Copy CSS token”, rồi “Copy HTML” từng thẻ; class .ar-* chỉ tham chiếu biến.

Danh mục đo được

3 pattern còn lại, dựng lại từ số đo (font, cỡ, màu quy về biến, bo, đệm, khung). Chữ của tác giả thay bằng chữ mẫu.

Trạng thái đo được

0 trạng thái còn lại, ép bằng CDP CSS.forcePseudoState: trái là nghỉ, phải là sau khi áp diff đo được. Focus của bài là viền 3px --relation, tự style chứ không phải viền mặc định của trình duyệt.
