Bộ thành phần của app duyệt hồ sơ

App viết bằng Next.js và Tailwind. Component không đi qua token: màu viết thẳng bằng hex trong class arbitrary như bg-[#16315e]. Vì vậy mọi màu ở đây là màu thực dùng, đo bằng getComputedStyle trên phần tử thật rồi đặt tên theo vai trò. Font Lexend Deca, icon Material Symbols Outlined.

Kit chỉ lấy style và cấu trúc. Tên người, mã hồ sơ, số tiền, phòng ban, loại hồ sơ, ảnh đại diện và wordmark đều thay bằng dữ liệu mẫu. Muốn dùng lại: dán khối --bb-* cùng CSS .bb-*, rồi copy HTML từ từng thẻ.
