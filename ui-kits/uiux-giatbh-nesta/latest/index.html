Nesta: bộ thành phần

Kit chép lại trang Nesta, một mock dashboard nhà thông minh dựng tay. Bản mock bên dưới là code thật của trang, chạy được: bấm menu trái để đổi màn, − / + chỉnh nhiệt độ, công tắc, tab và thanh chọn đều bấm được. Mock không có token màu riêng: bảng màu dưới đây gom từ CSS và script của trang. Vỏ site (header, chân trang) mặc token --aw-* sáng/tối; mock luôn tối.

Màu Color

Vỏ site --aw-*

Token của aw.css, đổi theo Sáng/Tối ở thanh trên.

Chữ Type
