Bộ thành phần của ChatGPT web

Mọi thành phần gặp được trên 17 trang ChatGPT bạn tự lưu (trang chủ, hồ sơ, plugin và 14 trang cài đặt), dựng lại bằng HTML/CSS thuần. Màu đọc thẳng từ CSS đã lưu bằng Playwright (offline, tắt JS), cả hai bộ theme có trong file: accent Tím bạn đang dùng và accent Mặc định (xanh), mỗi bộ đủ sáng lẫn tối. Kích thước, bo góc, cỡ chữ và các trạng thái hover/focus là số đo getComputedStyle của phần tử thật.

Mỗi thẻ ghi tên class hay token gốc của site và có nút copy HTML. Muốn dùng lại ở dự án khác thì dán khối --cg-* (nút “Copy CSS token”) cùng CSS .cg-*. Icon thay bằng Material Symbols, ảnh và tên thật thay bằng dữ liệu mẫu.

Màu

vai trò màu của lựa chọn đang bật. Mỗi ô ghi tên vai trò trong kit, biến gốc của site và mã hex (8 ký tự khi có alpha). Bấm để copy hex. Ô có alpha nằm trên nền ô bàn cờ để thấy độ trong.

Chữ

ChatGPT không tải webfont: chữ dùng font hệ thống (-apple-system-body, ui-sans-serif, system-ui…), nên trên máy Mac là SF Pro. Thang dưới đây là các cỡ đo được trên trang, kèm class hoặc token site dùng.

Bo góc

Mọi bán kính của site là calc(<base> * var(--corner-radius-scale)). Bản web đặt scale = 1; app desktop (Codex, electron) đặt 1.25 và thêm corner-shape: superellipse(1.5). Đổi “Bo góc” ở thanh trên để xem cả kit đổi theo. Nút và ô nhập dạng viên thuốc dùng 9999px nên không đổi.

Màn hình mẫu · 16 màn

Mỗi trang bạn đã lưu là một màn desktop 1440 × 900 (hai file “Cá nhân hóa” trùng nhau nên gộp làm một). Màn được ghép từ chính các class .cg-* ở trên, nên đổi màu nhấn, sáng/tối hay bo góc thì màn đổi theo. Nhãn cài đặt giữ như trang gốc; tên, email, địa chỉ, số thẻ, lịch sử chat và ảnh đã thay bằng dữ liệu mẫu. Mỗi màn chỉ hiện phần đầu trang vừa khung 900 như lúc mở. Không có màn mobile vì bộ trang lưu chỉ có bản desktop.
