Bộ thành phần của Openship

Hệ thiết kế đang chạy trên openship.io, dựng lại bằng HTML/CSS thuần. Site có hai bề mặt: trang tài liệu (Fumadocs, có sáng và tối) và trang marketing (chỉ có bản sáng, kèm các khối nền tối). Màu đọc từ CSS var của site, số đo lấy bằng getComputedStyle trên 32 trang. Mỗi thẻ ghi tên class gốc và có nút copy HTML; dán khối --os-* cùng CSS .os-* là dùng lại được. Chữ của site là Gellix (font có bản quyền); kit thay bằng Figtree.

Màu

Trên: 35 vai trò của trang docs (--color-fd-*, màu code Shiki, ba biến riêng của sidebar), đổi theo chế độ Sáng/Tối. Dưới: token của trang marketing (--th-*), site chỉ định nghĩa bản sáng. Bấm một ô để copy giá trị.

Token marketing--th-* → --os-m-*chỉ sáng
Nhóm kit ở cuối là các hằng số site viết thẳng trong CSS component (nền tối #0c0d12, màu dấu so sánh, màu tag), kit đặt tên để component không chứa mã màu rời.

Chữ

Site dùng Gellix cho mọi chữ và font mono hệ thống cho code. Bảng đầu là thang chữ đo được (size / line-height · weight). Bảng sau liệt kê từng kiểu chữ mà vòng khám phá gặp trên site, kèm class gốc.
