Bảng nghe nhạc

Dashboard app nghe nhạc tông kem và xanh xô thơm. Bấm thanh bên để đổi Thư viện / Thống kê, lọc thể loại, đổi tab Bài hát / Album, thả tim, phát / dừng. Nút trăng mở chế độ tối theo vòng tròn từ chỗ bấm.

Dựng lại từ reel của Code & Chill ("Music listening app dashboard", React). Viết lại bằng JS/CSS thuần, ảnh bìa thay bằng gradient, dữ liệu mẫu.
