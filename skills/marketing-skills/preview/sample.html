Executive Summary
  • Sức khoẻ on-page: yếu. Trang chưa nói được cho Google (và người dùng) quán bán gì, ở đâu.
  • Ưu tiên: (1) title, (2) NAP + địa chỉ dạng text, (3) cấu trúc H1/H2, (4) mô tả ảnh.
  • Thắng nhanh: sửa title + meta description chỉ mất vài phút.
Chưa kiểm được (không đoán):
  • robots.txt, sitemap, trạng thái index, Core Web Vitals: cần truy cập site / Search Console / PageSpeed.
  • Schema (JSON-LD): đoạn HTML tĩnh không đủ để kết luận «không có», đúng cảnh báo trong SKILL.md; cần Rich Results Test.

Prioritized Action Plan
  1. Critical: viết lại title; thống nhất NAP và đưa địa chỉ ra dạng text.
  2. High-impact: meta description; một H1 + H2 cho «Thực đơn».
  3. Quick wins: alt + tên tệp ảnh; thêm canonical.
  4. Dài hạn: kiểm Google Business Profile, trang thực đơn riêng, bài «cold brew là gì» (xem skill ai-seo / local-seo).
