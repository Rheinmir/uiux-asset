# SVG Spinners

首页用上游的 CSS 版逐个展示 46 种加载动效。每个动效可调整尺寸和颜色，并导出独立 HTML 或 React TSX。

- 来源：[Utkarsh Verma / SVG Spinners](https://github.com/n3r4zzurr0/svg-spinners/tree/abfa05c49acf005b8b1e0ef8eb25a67a7057eb20) · [原始许可](vendor/svg-spinners/LICENSE)
- `vendor/svg-spinners/` 包含上游的 CSS 和 SMIL 两种原始 SVG。
- `node gallery/svg-spinners/build.mjs` 生成预览使用的 SVG 数据。预览与导出的颜色和尺寸由外层样式控制。
