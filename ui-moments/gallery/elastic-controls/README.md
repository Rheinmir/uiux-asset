# 弹性控件

打开 [交互页](index.html)，可以手动操作三个控件，也可以点「播放演示」依次看一遍。主画廊通过三个哈希入口分别嵌入组件。

- [弹性滑尺](index.html#elastic-ruler)。数字滑块沿拖动方向变扁、拉长。超过刻度边缘时，数值停在端点，滑块可以继续拉伸一小段。
- [对齐拨片](index.html#alignment-switch)。切换居左、居中和居右时，深色拨片先拉长再收紧，图标经过深色拨片时反色，上方线条同步排布。
- [夹页键](index.html#bookmark-press)。点按切换收藏状态。键帽和书签分别形变，松手时一前一后弹起。

参考 [@yui540 的弹性 UI 演示](https://x.com/yui540/status/2120825584947487170) 的黑白灰配色、紧凑尺度与回弹节奏。控件用途、造型、排版与实现由 UI Moments 设计。图形由 CSS 绘制，源代码按项目 [MIT 许可证](../../LICENSE) 提供。
