# Micron 点击反馈

点击按钮触发原作的 CSS 动画。12 种反馈在首页逐个展示，支持键盘和减少动态效果设置。详情可复制带完整 MIT 许可的独立 HTML。

- 来源：[Webkul Micron.js](https://github.com/webkul/micron/tree/c46d1bd8f0cadddc635692bd61a1a0b2effaf987) · [原始许可](vendor/micron/LICENSE)
- UI Moments 提供中性浮雕按钮、深浅主题和可重复触发的交互。
- 本地打开 `/gallery/micron/index.html#jelly` 体验果冻回弹，其他效果由 `catalog.mjs` 定义。
